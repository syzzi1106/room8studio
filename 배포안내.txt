업로드 위치는 Cloudflare에 연결된 GitHub 운영 브랜치의 기존 index.html 위치입니다.
기존 파일은 백업 후 같은 이름만 덮어쓰세요. CNAME과 네이버 검색 인증 파일 등은 유지합니다.
폴더를 올리지 않고 index.html만 교체하면 이미지/음원/영상이 누락됩니다.
ZIP 자체를 저장소에 올리면 사이트가 교체되지 않습니다. 반드시 압축을 풀고 내용을 올리세요.

배포 확인
Cloudflare에서 가장 최근 커밋의 Production 배포가 성공했는지 확인하세요.
이번 index.html은 약 70KB입니다. 기존 25.6MB 파일이 남아 있다면 예전 버전입니다.
브라우저 강력 새로고침(Ctrl+Shift+R) 또는 새 시크릿 창에서 확인하세요.
코드 검색으로 room8-build 값을 확인할 수 있습니다.

검증 범위
운영 사이트에서 FAQ/상담/위치/푸터 HTML이 존재하는 것을 확인했습니다.
최적화 수정본은 로컬 PC 브라우저에서 상담/위치/푸터 정상 표시 및 영상 재생, JavaScript 오류 없음 확인.
사용자가 겪은 환경에서의 오류 재현과 새 운영 배포 확인은 아직 완료되지 않았습니다.
